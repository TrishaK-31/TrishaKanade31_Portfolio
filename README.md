# Trisha Kanade --- Personal Portfolio

A modern, responsive personal portfolio website showcasing my background
as an **Electronics & Telecommunication Engineering student** and
**Frontend Developer**.

The portfolio presents my technical skills, projects, education,
internships, workshops, certifications, and professional contact
information in a clean and recruiter-friendly interface.

## 🌐 Live Portfolio

**Visit the live website:**  
https://trisha-kanade31-portfolio.vercel.app/

## 🚀 Getting Started

### 1. Clone the repository

``` bash
git clone https://github.com/trishakanade/TPortfolio.git
cd TPortfolio
```

### 2. Install dependencies

``` bash
npm install
```

### 3. Start the development server

``` bash
npm run dev
```

The development server runs on port `3000`.

### 4. Create a production build

``` bash
npm run build
```

### 5. Preview the production build

``` bash
npm run preview
```
